# 🎮 Gears of War E-Day — исправление ошибки elias-gutpuncher

**Скрипт для Steam-версии: убирает ошибку входа `elias-gutpuncher` за пару кликов и потом возвращает всё как было**

[![Release](https://img.shields.io/github/v/release/NiktarioN/gow-eday-elias-gutpuncher-fix)](https://github.com/NiktarioN/gow-eday-elias-gutpuncher-fix/releases/latest)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## 🤔 Что это и кому нужно

Если Gears of War E-Day в Steam не пускает тебя в игру и пишет `elias-gutpuncher`, одна из причин — российские сертификаты шифрования (ГОСТ), которые ставят КриптоПро, Госуслуги, ФНС и банки. Если дело в них, скрипт поможет: на время игры он убирает их из списка доверенных сертификатов Windows, а после игры возвращает обратно

Решение нашли игроки в [обсуждении в Steam](https://steamcommunity.com/app/3010850/discussions/0/588439235122634429), подробнее — в разделе [Благодарности](#-благодарности)

> ⚠️ Пока сертификаты убраны, не будут работать ЭЦП, КриптоПро, сайты Госуслуг, ФНС и банков, которым они нужны. Поиграл — верни сертификаты

## 📥 Как скачать

1. Открой страницу [последней версии](https://github.com/NiktarioN/gow-eday-elias-gutpuncher-fix/releases/latest)
2. Внизу, в разделе **Assets**, нажми на `GowEdayEliasGutpuncherFix.zip` — архив скачается
3. Найди архив в загрузочной папке и распакуй его
4. После распаковки будет папка с файлами `start`, `fix` и `README`

> ❗ Не запускай `start` прямо из архива — сначала обязательно распакуй его, иначе скрипт не найдёт свои файлы

## 🕹️ Как пользоваться

1. Дважды нажми на `start` и в окне «Разрешить этому приложению вносить изменения?» нажми **Да**
2. Введи `1` и нажми Enter — сертификаты уберутся. Окно можно закрыть. Запускай игру из Steam как обычно
3. Наигрался — снова запусти `start`, введи `2` и нажми Enter. Сертификаты вернутся, ЭЦП снова работает

Вверху окна всегда видно, что сейчас с сертификатами: установлены они или убраны

> 💡 **Не работает ЭЦП после игры?** Запусти `start` и выбери пункт `2`

> 🌐 **Игра всё равно не подключается?** Скорее всего, понадобится ещё включить VPN или использовать Zapret

## 🛡️ Окна при первом запуске

Windows настороженно относится к любым скачанным из интернета файлам без цифровой подписи, поэтому при первом запуске может появиться одно из окон:

| Окно                                                                | Что нажать                                                                    |
| ------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| «Система Windows защитила ваш компьютер»                            | **Подробнее** → **Выполнить в любом случае**                                  |
| «Не удаётся проверить издателя»                                     | **Запустить**                                                                 |
| «Разрешить этому приложению вносить изменения на вашем устройстве?» | **Да** — скрипту нужны права администратора, чтобы менять список сертификатов |

## 🆘 Если что-то пошло не так

| Что случилось                                                 | Что делать                                                                                                                        |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Не работают ЭЦП, КриптоПро или Госуслуги                      | Запусти `start` и выбери `2`                                                                                                      |
| Выключился свет или компьютер, пока сертификаты были убраны   | Ничего страшного: включи компьютер, запусти `start` и выбери `2` (или снова играй)                                                |
| Закрыл окно скрипта посреди работы                            | Запусти `start` ещё раз — он покажет, что произошло. `2` вернёт всё, `1` доделает удаление                                        |
| Скрипт пишет «Файл сессии был повреждён»                      | Выбери `2` — скрипт вернёт сертификаты из последней целой копии                                                                   |
| Игра всё равно выдаёт ошибку                                  | Верни сертификаты(`2`) и попробуй другие решения                                                                                  |
| Скрипт пишет «Сертификаты вернулись, отменено»                | Их возвращает какая-то программа на компьютере (обычно КриптоПро или настройки организации). На этом компьютере скрипт не поможет |
| Скрипт пишет «Копия повреждена или изменена»                  | Ничего не удаляй и создай [обращение](https://github.com/NiktarioN/gow-eday-elias-gutpuncher-fix/issues) с текстом ошибки         |
| Удалил папку с копией, пока сертификаты были убраны           | Вернуть их скрипт уже не сможет. Установи сертификаты заново с сайтов КриптоПро, Минцифры и ФНС                                   |
| Скрипт пишет «ГОСТ-сертификатов нет, этот фикс тебе не нужен» | Другая причина ошибки                                                                                                             |

## ❗ Важно

- Не удаляй папку `C:\ProgramData\GowEdayEliasGutpuncherFix`, пока не вернул сертификаты — там лежит их копия
- Если на компьютере несколько учётных записей Windows, пока сертификаты убраны, ЭЦП не работает ни у кого из них
- Скрипт можно запускать сколько угодно раз: он сам видит, что уже сделано, и не удалит и не вернёт лишнего

## 🔍 Для тех, кто хочет проверить

|                 |                                                                                                                                                                             |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Что меняет      | Убирает из `Cert:\LocalMachine\Root` сертификаты, у которых ключ ГОСТ (OID `1.2.643.*`), и возвращает их обратно                                                            |
| Что не трогает  | `CurrentUser\Root`, закрытые ключи, криптопровайдеры, службы, политики, автозагрузку. Ничего не скачивает и не работает в фоне                                              |
| Где копии       | `C:\ProgramData\GowEdayEliasGutpuncherFix\sessions`. Доступ только у администраторов и SYSTEM, каждый файл сверяется по SHA-256 перед возвратом. Хранятся 3 последние копии |
| Из чего состоит | `start.cmd` запрашивает права администратора и запускает `fix.ps1`, в котором вся логика. Код открыт — его можно прочитать перед запуском                                   |
| Требования      | Windows 10 или 11, встроенный Windows PowerShell 5.1                                                                                                                        |
