# 🎮 Gears of War E-Day. Исправление ошибки elias-gutpuncher

**Скрипт для Steam-версии. Убирает ошибку входа `elias-gutpuncher` и потом возвращает всё как было**

[![Release](https://img.shields.io/github/v/release/NiktarioN/gow-eday-elias-gutpuncher-fix)](https://github.com/NiktarioN/gow-eday-elias-gutpuncher-fix/releases/latest)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## 🤔 Что это и кому нужно

Если Gears of War E-Day в Steam не пускает вас в игру и пишет `elias-gutpuncher`, то одна из причин — российские сертификаты шифрования (ГОСТ), которые ставят КриптоПро, Госуслуги, ФНС и банки. Если дело в них, то скрипт поможет: на время игры он убирает их из списка доверенных сертификатов Windows, а после игры возвращает обратно

Решение нашли игроки в [обсуждении в Steam](https://steamcommunity.com/app/3010850/discussions/0/588439235122634429), подробнее — в разделе [Благодарности](#-благодарности)

> ⚠️ Пока сертификаты убраны, не будут работать ЭЦП, КриптоПро, сайты Госуслуг, ФНС и банков, которым они нужны. Поиграли — верните сертификаты

## 📥 Как скачать

1. Откройте страницу [последней версии](https://github.com/NiktarioN/gow-eday-elias-gutpuncher-fix/releases/latest)
2. Внизу, в разделе **Assets**, нажмите на `GowEdayEliasGutpuncherFix.zip` — архив скачается
3. Найдите архив в папке для загрузок и распакуйте его
4. После распаковки будет папка с файлами `start`, `fix` и `README`

> ❗ Не запускайте `start` прямо из архива — сначала обязательно распакуйте его, иначе скрипт не найдёт свои файлы

> 💡 **Совет:** для удобства переместите папку на рабочий стол — так её будет проще найти и не потерять

## 🕹️ Как пользоваться

1. Дважды нажмите на `start` и в окне «Разрешить этому приложению вносить изменения?» нажмите **Да**
2. Введите `1` и нажмите Enter — сертификаты уберутся. Окно можно закрыть. Запускайте игру из Steam как обычно
3. Поиграли — снова запустите `start`, введите `2` и нажмите Enter. Сертификаты вернутся, ЭЦП снова работает

Вверху окна всегда видно, что сейчас с сертификатами: установлены они или убраны

> 💡 **Не работает ЭЦП после игры?** Запустите `start` и выберите пункт `2`

> 🌐 **Игра всё равно не подключается?** Скорее всего, понадобится ещё включить VPN или использовать Zapret

## 🛡️ Окна при первом запуске

Windows настороженно относится к любым скачанным из интернета файлам, поэтому при первом запуске может появиться одно из окон:

| Окно                                                                | Что нажать                                                                    |
| ------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| «Система Windows защитила ваш компьютер»                            | **Подробнее** → **Выполнить в любом случае**                                  |
| «Не удаётся проверить издателя»                                     | **Запустить**                                                                 |
| «Разрешить этому приложению вносить изменения на вашем устройстве?» | **Да** — скрипту нужны права администратора, чтобы менять список сертификатов |

## 🆘 Если что-то пошло не так

| Что случилось                                                 | Что делать                                                                                                                        |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Не работают ЭЦП, КриптоПро или Госуслуги                      | Запустите `start` и выберите `2`                                                                                                  |
| Выключился свет или компьютер, пока сертификаты были убраны   | Ничего страшного: включите компьютер, запустите `start` и выберите `2` (или снова играйте)                                        |
| Закрыли окно скрипта посреди работы                           | Запустите `start` ещё раз — он покажет, что произошло. `2` вернёт всё, `1` доделает удаление                                      |
| Скрипт пишет «Файл сессии был повреждён»                      | Выберите `2` — скрипт вернёт сертификаты из последней целой копии                                                                 |
| Игра всё равно выдаёт ошибку                                  | Верните сертификаты (`2`) и попробуйте другие решения                                                                             |
| Скрипт пишет «Сертификаты вернулись, отменено»                | Их возвращает какая-то программа на компьютере (обычно КриптоПро или настройки организации). На этом компьютере скрипт не поможет |
| Скрипт пишет «Копия повреждена или изменена»                  | Ничего не удаляйте и напишите об ошибке — инструкция в разделе [Помощь](#-помощь)                                                 |
| Удалили папку с копией, пока сертификаты были убраны          | Вернуть их скрипт уже не сможет. Установите сертификаты заново с сайтов КриптоПро, Минцифры и ФНС                                 |
| Скрипт пишет «ГОСТ-сертификатов нет, этот фикс тебе не нужен» | Другая причина ошибки                                                                                                             |

## ❗ Важно

- Не удаляйте папку `C:\ProgramData\GowEdayEliasGutpuncherFix`, пока не вернули сертификаты — там лежит их копия
- Если на компьютере несколько учётных записей Windows, то пока сертификаты убраны, ЭЦП не работает ни у кого из них
- Скрипт можно запускать сколько угодно раз: он сам видит, что уже сделано, и не удалит и не вернёт лишнего

## 🔍 Для тех, кто хочет проверить все сам

|                 |                                                                                                                                                                             |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Что меняет      | Убирает из `Cert:\LocalMachine\Root` сертификаты, у которых ключ ГОСТ (OID `1.2.643.*`), и возвращает их обратно                                                            |
| Что не трогает  | `CurrentUser\Root`, закрытые ключи, криптопровайдеры, службы, политики, автозагрузку. Ничего не скачивает и не работает в фоне                                              |
| Где копии       | `C:\ProgramData\GowEdayEliasGutpuncherFix\sessions`. Доступ только у администраторов и SYSTEM, каждый файл сверяется по SHA-256 перед возвратом. Хранятся 3 последние копии |
| Из чего состоит | `start.cmd` запрашивает права администратора и запускает `fix.ps1`, в котором вся логика. Код открыт — его можно прочитать перед запуском                                   |
| Требования      | Windows 10 или 11, встроенный Windows PowerShell 5.1                                                                                                                        |
